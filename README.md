## 📖 About The Project

**Firdaus Residence** is a modern front-end web application designed specifically for the real estate and property business. This website offers a seamless property browsing experience, enriched with beautiful and modern animations. It allows potential buyers to explore every detail of their dream houses or villas interactively.

## 🌟 Key Pages & Features

This platform consists of several integrated main pages:

- 🏠 **Homepage:** An engaging landing page with a hero section and featured properties overview.
- 🏢 **Property Types (Product List):** A comprehensive catalog of houses and villas available for sale or rent.
- 🔍 **Property Details (Product Detail):** In-depth information regarding facilities, pricing, and property galleries.
- 📰 **Blog:** Articles, tips, and tricks regarding interior design and property investment.
- 📝 **Blog Detail:** A dedicated page for a comfortable full-article reading experience.
- ℹ️ **About Us:** Information about the Firdaus Residence company and property agency.
- 📞 **Contact:** Contact information and a direct inquiry form.

## 🛠️ Tech Stack & Tools

To create a dynamic and highly responsive UI/UX, this project utilizes a combination of:

* **Structure & Styling:** HTML5 & CSS3
* **Interactivity:** Vanilla JavaScript
* **CSS Framework:** Bootstrap (Ensuring mobile-first responsiveness)
* **Animations:** * [GSAP (GreenSock)](https://greensock.com/gsap/) - For advanced and smooth UI animations.
  * [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/) - For beautiful scroll-reveal effects.
